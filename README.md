# ⛏️ MSS (Minecraft Simple Server)

Современная локальная веб-панель для создания и управления серверами **Minecraft** прямо с вашего ПК.

Интерфейс выполнен в аутентичном стиле **Minecraft Edition**:
- Пиксельная типографика (`Press Start 2P`, `Silkscreen`, `VT323`), текстуры блоков, 3D-кнопки с фасками и интерактивный сплэш-текст;
- Атмосферный живой фон с частицами биомов, сферами опыта (XP Orbs) и парящими рунами стола зачарований (`Standard Galactic Alphabet`);
- Переключатель **Light / Dark Mode**, отключение спецэффектов (**FX**), звуковой движок из оригинальных сэмплов Minecraft и переключение языка **EN / RU**;
- Инспектор инвентаря игроков в реальном времени, пресеты конфигурации в 1 клик, ползунок дальности прорисовки и живая консоль на WebSockets.

---

## ✨ Возможности и функционал

### 1. 🧱 Стиль Minecraft Edition (Light / Dark Mode + EN / RU)
- **Аутентичный визуал**: каменные панели, дубовая боковая панель, 3D-бевел слоты и тултипы в стиле предметов Minecraft.
- **Живой атмосферный фон**: мягкое свечение биомов, парящие споры, пульсирующие сферы опыта и галактические руны с легким параллаксом.
- **Двуязычный интерфейс (EN / RU)**: английский язык по умолчанию с мгновенным переключением на русский в верхней панели (`localStorage`).

### 2. ⚡ Пресеты сервера в 1 клик
Быстрое применение оптимальных настроек:
- **«Легкий Vanilla»**: 2 GB RAM, 2 ядра CPU, прорисовка 8 чанков.
- **«Оптимизированный Paper»**: 4 GB RAM, 4 ядра CPU, прорисовка 10 чанков, полные флаги оптимизации Aikar.
- **«Производительный Fabric»**: 6 GB RAM, 4 ядра CPU, прорисовка 10 чанков.
- **«Тяжелый Forge»**: 8 GB RAM, 6 ядер CPU, прорисовка 12 чанков, флаги для модпаков.
- **«Экстремальный сервер»**: 16 GB RAM, 8+ ядер, прорисовка 16 чанков.

### 3. 🌐 Динамический выбор абсолютно всех версий
- Прямая подгрузка официальных списков релизов с API:
  - **Vanilla**: 100+ официальных релизов Mojang (от 1.21 до 1.0);
  - **Paper / Purpur**: все релизы с поддержкой плагинов;
  - **Fabric**: актуальные релизы загрузчика модов;
  - **Forge**: классические версии;
- Возможность свободного ввода любой кастомной версии.

### 4. 🔭 Дальность прорисовки (Render Distance)
- Ползунок настройки от **2 до 32 чанков**.
- Автоматически синхронизируется с параметром `view-distance` в файле `server_data/server.properties`.

### 5. 🔌 Исправленная живая консоль (WebSockets)
- Привязка к активному Event Loop FastAPI/Uvicorn с потоковой отправкой каждой строки процесса Java.
- Логи поступают в браузер **в реальном времени** без задержек и без необходимости обновлять страницу.
- Автоматическая плавная прокрутка вниз, heartbeat-пинг и автоматическое переподключение при разрывах связи.
- Поле ввода серверных команд (`op`, `gamemode`, `stop`, `say`) и кнопки быстрых команд.

### 6. 📦 Менеджер модов и плагинов (Drag & Drop)
- Перетаскивание `.jar` файлов из проводника прямо в браузер.
- Автоматическая маршрутизация: сохраняет в `plugins/` для Paper или в `mods/` для Fabric/Forge.
- Включение/отключение файлов в 1 клик (`.disabled`) и удаление.

## 🚀 Быстрый запуск

### Запуск в 1 клик на Windows
Дважды кликните по файлу:
```bat
run.bat
```
Панель управления автоматически откроется в браузере по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000).

### Ручной запуск через консоль
```powershell
python run.py
```

## ☕ Требования к Java

Для серверов Minecraft необходима установленная Java:
- Для версий **1.20.5+**: рекомендуется **Java 21**.
- Для версий **1.18 — 1.20.4**: рекомендуется **Java 17**.
- Для версий **1.16.5 и старее**: подходит **Java 8** или **Java 11**.

В конфигурационном файле `server_config.json` можно настроить путь к Java через параметр `"java_path"` (по умолчанию `"java"`).
